# 🏪 پیش‌بینی فروش فروشگاه
# زبان : [🇬🇧 English](README.md)
یک پروژه یادگیری ماشین برای پیش‌بینی میزان فروش فروشگاه با استفاده از اطلاعات مربوط به مشتری، محصول، قیمت، تخفیف، تبلیغات و تعداد بازدیدکنندگان.

## 📌 درباره پروژه

در این پروژه از الگوریتم **Linear Regression** برای پیش‌بینی میزان فروش استفاده شده است.

دیتاست شامل **۱۵۰۰ رکورد مصنوعی** است.

## 🧠 یادگیری ماشین

- نوع مسئله: **Regression**
- الگوریتم: **Linear Regression**
- کتابخانه: **Scikit-learn**
- معیار ارزیابی: **R² Score**

## 📊 ویژگی‌های دیتاست

- `customer_age` — سن مشتری
- `customer_gender` — جنسیت مشتری
- `customer_type` — نوع مشتری
- `product` — محصول
- `category` — دسته‌بندی محصول
- `price` — قیمت
- `discount_percent` — درصد تخفیف
- `advertising_spend` — هزینه تبلیغات
- `store_visitors` — تعداد بازدیدکنندگان
- `weekend` — آخر هفته بودن
- `season` — فصل
- `sales` — مقدار فروش

## ⚙️ تکنولوژی‌های استفاده‌شده

- Python
- Pandas
- NumPy
- Scikit-learn

دیتاست این پروژه مصنوعی است، بنابراین این امتیاز نباید به‌عنوان عملکرد مدل روی داده‌های واقعی در نظر گرفته شود.
