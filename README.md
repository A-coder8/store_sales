# 🏪 Store Sales Prediction

A Machine Learning regression project that predicts store sales using customer, product, pricing, advertising, and visitor data.
Language : [🇮🇷 فارسی](README.fa.md)
## 📌 Project Overview

In this project, a **Linear Regression** model is used to predict store sales based on different features related to customers, products, pricing, discounts, advertising, and store visitors.

The dataset contains **1500 synthetic records**.

## 🧠 Machine Learning

- Problem Type: **Regression**
- Algorithm: **Linear Regression**
- Library: **Scikit-learn**
- Evaluation Metric: **R² Score**

## 📊 Features

- `customer_age` — Customer age
- `customer_gender` — Customer gender
- `customer_type` — Customer type
- `product` — Product name
- `category` — Product category
- `price` — Product price
- `discount_percent` — Discount percentage
- `advertising_spend` — Advertising expenditure
- `store_visitors` — Number of store visitors
- `weekend` — Whether the day is a weekend
- `season` — Season
- `sales` — Target value

## ⚙️ Technologies

- Python
- Pandas
- NumPy
- Scikit-learn

## Note

The dataset is synthetic, so this score should not be interpreted as real-world model performance.
